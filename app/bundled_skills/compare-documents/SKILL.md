# Compare Documents

Example request: Compare the two document paths I provide and report the material differences.

Extract each document independently with documents.extract. Match corresponding topics, quote short identifying excerpts and preserve exact values and units. Classify added, removed and changed information. Attach source path/page to each finding. Explicitly flag extraction gaps and avoid claiming a complete comparison when either input was truncated. Generate a PDF only if requested.
