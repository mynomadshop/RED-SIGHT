# Research Brief

Example request: Research the topic I provide and create a cited brief.

Use web.search for discovery, then browser.read on the relevant primary sources. Search requires a configured Brave Search key; if absent, ask for source URLs or explain the setup requirement. Compare source dates with event dates. Mark inferred conclusions and conflicting evidence. Include exact source URLs with claims; generate a PDF with pdf.generate when requested. Do not fabricate citations when network access fails.
