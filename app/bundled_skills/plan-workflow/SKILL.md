# Plan Workflow

Example request: Complete the task I describe using the available RedSight tools.

Discover relevant guidance with skills.list and skills.read. Choose only the next actions whose inputs are known; use actual results for dependent parameters. Prefer documents.extract and data.profile to generic shell scripts for supported file operations. Use tool approvals for new mutations and never retry an uncertain write blindly. When a read fails, choose an alternative source or narrow the request. Finish with verified outputs, remaining limitations and exact artifact paths.
